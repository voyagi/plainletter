Nothing printed that is not in the letter

What arrives

A photograph Sideways, shadowed, creased. Taken on the visitor's phone at the counter.
A PDF Born digital, so its own text layer is the ground truth.
Typed text Pasted at the desk, or one of twelve synthetic sample letters.

into the reading

What the visitor takes home

A one page desk card Two languages side by side, in the monochrome a library printer has. Every mark numbered against the words it was drawn under.
A calendar reminder The deadline, with an alarm three days ahead of it.
A case number, if asked for Only with consent. Printed on the card, and the only key to the record.

What is never kept

The letter itself The picture and its words live only for the length of the reading. Never written to disk, never in a log, never in a trace.
Anything at all, without consent A consented case holds checked, masked values for thirty days and nothing else.

What holds the model to the letter

The grounding guard

on 7, 8, 9

A Strands intervention on the answer tool. A date or amount the check did not ground is refused before it exists, the refusal goes back as the tool's result, and the model writes again. guard.py

The knowledge base, as a tool

on 8, 9

Twelve senders, each route carrying the official page it was read on and the date. Unverified senders say so and route to a person. tools.py, kb.py

The audit hook

on 2, 3, 7, 8, 9

Every tool call and how it ended. What the letter said is never in it.

One last look, outside the agent

after 7, 8, 9

The pipeline re-reads what came through and refuses the whole reading if a stray value survived anyway. A refused reading is recoverable. A confident wrong deadline is not.

Masked before it is shown

on 5, 9, 10

The citizen number and the bank account are masked everywhere the text is displayed, printed, logged or remembered. redact.py

Where it runs

The desk console

Next.js. The browser never holds an AWS credential: a server route signs InvokeAgentRuntime and streams each stage back as it finishes.

AgentCore Runtime

The same src/ directory zipped with its dependencies, arm64, Python 3.11, Frankfurt. It runs locally on port 8080 with the identical entrypoint.

Amazon Bedrock

EU inference profiles from eu-central-1, so the letter is processed in the EU. Reading and drafting are separate settings.

Memory and traces

AgentCore Memory keeps a consented case as checked, masked values for thirty days. Every prompt, answer and tool argument reads REDACTED in the spans.
